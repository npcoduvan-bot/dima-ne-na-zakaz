# НЕ НА ЗАКАЗ — фотографии Димы

Исходники опубликованной версии 11 сайта «НЕ НА ЗАКАЗ». Это статический сайт без сборки и внешних зависимостей. Рабочие файлы находятся в `dist/`; фотографии и шрифты хранятся локально в `dist/assets/`.

## Локальный просмотр

Запустите любой локальный статический сервер из каталога `dist/`, например `python -m http.server 8000 --directory dist`, и откройте `http://localhost:8000`. Открытие `index.html` как локального файла может отличаться от работы опубликованного сайта.

## Публикация на Cloudflare Pages

- Репозиторий: `npcoduvan-bot/dima-ne-na-zakaz`
- Основная ветка: `main`
- Framework preset: `None`
- Build command: оставить пустой
- Build output directory: `dist`

При подключении репозитория Cloudflare Pages публикует изменения ветки `main` автоматически. Исходный проект ChatGPT Sites существует отдельно.

## Редактирование

- Тексты и ссылки первого экрана, разделов и подвала: `dist/index.html`.
- Цвета, размеры, адаптивная верстка и квадратная карточка чёрного кота: `dist/style.css`. Для карточки используется `.hero-inset`; исходная фотография не меняется, обрезка задаётся через `object-fit` и `object-position`.
- Поведение фильтров, кнопки случайного кадра, просмотра и подгрузки: `dist/app.js`.
- Порядок 186 кадров, подписи, категории и пути к изображениям: `dist/photos.js`. Категории: `ride`, `life`, `around`, `detail`.
- Фотографии и миниатюры: `dist/assets/`. У каждой записи в `photos.js` должны существовать файлы `src`, `fullImage`, `thumbnail` и оба размера из `srcSet`. Большие файлы загружаются по требованию, миниатюры — постепенно.

Для новой фотосерии добавьте оптимизированные оригиналы и миниатюры в `dist/assets/`, затем записи с уникальными `id` и `displayNumber` в `dist/photos.js`. Существующие номера не переназначайте: они используются в подписях. Список номеров, ранее исключённых из архива, находится в `scripts/removed-photos.json`.

После правок проверьте сайт на компьютере и телефоне. Скрипт `scripts/validate-assets.py` проверяет записи и изображения; для него нужны Python, Pillow и fontTools. При добавлении фотографий обновите ожидаемое число записей в этом скрипте.

Фотографии и оформление принадлежат их правообладателям; этот репозиторий не предоставляет разрешения на их повторное использование.
